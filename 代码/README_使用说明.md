# 智享杯联合配置策略复现包

2026-10-31：正式研报阅读入口更新为`docs/strategy-report/report.pdf`；原提交PDF保留。公开衍生结果的制图脚本在`docs/strategy-report/`，可无供应商输入运行，与本说明的完整账户/训练入口有区别。本次报告修订没有改动下述策略和账户代码。

本代码包通过相邻的`数据/`读取冻结E00排名、训练面板和真实账户输入。在整理版中报告位于`docs/`；不依赖原研究档案绝对路径、掘金登录或GPU。代码只读输入，结果写到`--output-dir`指定目录。

## 环境

实测账户环境：Windows 11、Python 3.12.7、NumPy 1.26.4、pandas 2.2.2、SciPy 1.13.1、scikit-learn 1.5.1、PyArrow 16.1.0。E00重训另需LightGBM 4.7.0。复现账户使用CPU；无需MATLAB、Torch或掘金SDK。Linux/macOS未测。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r 代码\requirements.txt
```

若系统的`python`版本不为3.12，请先选择Python 3.12解释器创建虚拟环境。

## 快速账户复现（不训练）

该入口使用包内已冻结的2023—25 E00评分，重新排序并运行完整股票/ETF共享现金账户；配置权重和风险预算在运行时重算。它不是“仅读取summary”，会生成六套逐日净值、成交、ETF订单、持仓事件和目标权重账本。

```powershell
python 代码\run_reproduce.py --data-root 数据 --output-dir 本地复现输出 --ranking-mode frozen
python 代码\verify_results.py --data-root 数据 --output-dir 本地复现输出
```

六套账户为2023标准验证的RISK_B1和固定25%，以及2024—25标准/压力的两方案账户。压力情景按合同提高交易费用和滑点。`verify_results.py`独立重算净值恒等式、成交费用与名义金额，并与包内冻结参考比较。

## 完整E00因果训练与账户复现

该入口逐月重训2020—25共72个E00模型，窗口36个月、标签成熟截止、固定LightGBM参数、每个训练日期等权；随后用新评分运行同样的六套账户。程序会将2023—25重训评分与冻结评分按日期/证券键比较，并在复现摘要中记录最大差、键覆盖和排名是否完全一致。

```powershell
python 代码\run_reproduce.py --data-root 数据 --output-dir 本地重训复现输出 --ranking-mode retrain
python 代码\verify_results.py --data-root 数据 --output-dir 本地重训复现输出
```

也可以单独重训并保存模型/评分：

```powershell
python 代码\train_e00.py --data-root 数据 --output-dir 本地训练输出
```

默认冻结评分快速回放在ZIP解压目录实测70.02秒，包含六个账户；72个月度E00单独重训实测49.92秒，完整重训后再运行六账户总计125.78秒。测试主机为Windows、Python 3.12.7、LightGBM 4.7.0、4线程CPU；不同CPU和线程效率会影响耗时。建议至少8GB内存；这是运行建议，不是实测最低值。重训失败时仍可用frozen入口作账户回放，但不得把它写成训练复现。

## 冻结规则与输出

- E00股票池与每日候选顺序沿用冻结模型评分；账户持有、整手、T+1、费用、股息、公司行动和并购由共享账本处理。
- 固定25%目标为股票、标普500 ETF、黄金ETF、国债ETF各25%；RISK_B1按目标风险贡献45/30/20/5，每20个交易日用60日协方差、50%收缩到对角线，权重约束和求解目标详见代码的`src/run_dynamic_risk_trend_v1.py`。
- 2024—25是已被多轮研发查看的探索期，不是盲测。2026最终组合的175日现金重启回放已由独立入口完成，见下文；未封装2026重新训练入口。
- 单股交易可行性、整手、上限和共享现金使实际股票比例不同于目标比例；账户汇总要同时读目标权重和实际日账。
- 包内`代码/models/E00/`保存历史月度E00模型文本作为冻结参考；快速回放使用排名文件，不静默加载或重训模型。
- 费用和NAV受核心数据/成本契约约束；升级Python依赖后先看验证差异，不应以summary替代账户运行。

## 数据与范围

字段、源SHA、处理方法和执行凭据见`数据/数据字典与来源.md`与`数据/MANIFEST.json`。账户行情覆盖2023—25，按每个评价期初始新资本；股票及ETF公司行动输入覆盖引擎运行所需来源。重训面板保留2017起历史以支撑2020首月36个月窗口，标签按实际成熟终点过滤。重新分发这些行情/事件文件的权利没有在本次打包流程中核验；不要公开上传数据包。

主要结果参考：B1在2023验证Sharpe 2.837；2024—25标准总收益27.80%、Sharpe2.858、回撤−3.38%，压力总收益27.03%、Sharpe2.742。固定25%同期标准总收益46.13%、Sharpe2.642、回撤−5.55%；压力总收益44.40%、Sharpe2.556、回撤−5.60%。B1的风险调整指标更高但收益更低，实际仓位也更偏国债。数字为历史模拟，不构成收益承诺。


## 2026冻结评分延伸复现

独立入口`代码/run_2026_extension.py`读取本包相邻`数据/`中的2026账户行情、E00冻结评分、规范化公司行动事件，以及既有四ETF成交价与风险代理历史。它从2026年初各自100万元现金起步，运行RISK_B1与固定25%两种方案的标准/压力四账本，输出逐日净值、成交、目标权重、ETF订单、事件及拒单记录，并记录各输入SHA-256。9个E00月度模型文本保存在`数据/models/E00_2026/`作为模型版本凭据；此入口使用同月已冻结评分，不重新拟合。

```powershell
python 代码\run_2026_extension.py --data-root 数据 --output-dir 本地2026复现输出
```

测试环境是Python 3.12.7、Windows、CPU；本机运行约20秒。该期从2026-01-05至2026-09-21共175个交易日，不是完整年度，且是已查看过的延伸期，不能称为盲测；账户不承接2025年末持仓。2026数据包没有加入环境变量、登录信息或数据凭据。当前封装保留原始精度，不裁减原有2023—25输入。

2026完整训练入口没有并入复现包：原训练脚本受研究档案的SHA绑定与一次性执行授权约束，并依赖多份封存特征、成分、事件裁决与费用验收输入；此交付只提供经确认的9个月模型文本和冻结预测，用于可复现账户回放。既有`train_e00.py`仍只负责原2020—25因果训练。
