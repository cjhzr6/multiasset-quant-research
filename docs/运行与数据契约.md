# 运行与数据契约

更新：2026-11-05。新增公开样例仅用于演示风险预算实现；行情为固定随机种子合成数据，不是历史策略收益。测试只覆盖风险预算权重的和、上限、非负性及再平衡频率，不代替完整账户复现或财务/数据审计。

## 无供应商数据的公开检查

在`GitHub项目/`运行：

```powershell
python -m pip install -r 代码/requirements.txt pytest
python -m pytest -q tests
python examples/synthetic_risk_budget.py
```

Linux CI仅运行Python测试与样例，不编译中文PDF。样例调用现有`代码/src/run_dynamic_risk_trend_v1.py`，不改策略实现。

## 完整回放的数据前提

账户/训练/2026扩展入口需要用户合法取得并解压到`数据/`的项目数据包。该目录由Git忽略，不得上传供应商行情、事件、新闻、账户输入或凭证。

- `run_reproduce.py --ranking-mode frozen`：冻结E00评分的六账户回放，不训练。
- `--ranking-mode retrain`：2020—2025的72次月度E00训练后回放。
- `run_2026_extension.py`：2026年175交易日冻结评分现金重启回放，不训练。
- `verify_results.py`：检查账户恒等式、成交、费用、现金和冻结参考差异。

每次运行应写入独立`--output-dir`，记录数据与代码SHA、命令、退出码和实际验证结果。公开README与结果表不得把冻结回放称作训练，也不得把2026扩展称作全年、盲测或实盘结果。
