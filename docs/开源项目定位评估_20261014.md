# 开源项目定位评估（2026-10-14）

## 历史计划与当前状态

2026-11-05：下文保留10月14日定位判断。当前已增加合成风险预算样例、轻量测试/CI配置、中英README、MIT、引用与贡献指南，见[发布核查](发布核查_20261105.md)。统一可安装接口及完整会计单元测试仍未实现，不将历史缺项全部当成当前缺项。

## 10月14日安排

2026-10-14用户要求先简要保存、优先推进富国基金比赛。本改造计划暂缓实施；旧比赛、正式ZIP及验收证据保持冻结。后续先实现公开合成数据演示，再抽取接口、补充会计测试与文档，不以增加策略数量为目标。本次仅保存计划，没有进行重构或公开上传。

本轮是用户询问能否将公开目录建设为优秀开源项目后的定位讨论，没有改动策略或启动产品重构，也没有上传GitHub。

参考官方仓库：
- Qlib：https://github.com/microsoft/qlib —— 数据、模型、评估、策略与研究流程；提供数据准备文档。
- VectorBT：https://github.com/polakowo/vectorbt —— 批量回测、数组运算、参数实验与交互分析。
- VeighNa：https://github.com/vnpy/vnpy —— 量化交易平台和模块生态。
- Backtesting.py：https://github.com/kernc/backtesting.py —— 简单API、可立即运行的示例、教程与图表。
核验日期2026-10-14。Star数量动态变化，不作为策略获利或正确性的证据；上述共同特征与受欢迎程度之间不作因果结论。

当前项目定位仍以比赛归档和特定输入复现为主，公开用户缺少原本地数据、不能直接运行完整实验；恢复入口还依赖私有研究脚本和历史布局。暂无统一可安装包、面向新数据的稳定策略接口、公开可运行演示、CI工作流、正式许可证和贡献指南。内部账本一致性及历史结果吻合不等于独立交易规则认证。

建议定位：A股与境内ETF的可审计回测和策略比较工具。优势候选为整手/T+1/交易费用/公司行为的显式账本、股票与ETF共享现金、多方法同账户对照及负结果记录。与成熟项目比较时应核对实际交易规则覆盖，不宣称唯一或全面更准确。

优先顺序：
1. 公开用户零账号、零私有目录可运行一个标注为合成数据的演示；展示执行、费用、资产配置、净值与失败案例，合成演示不用于宣传历史收益。历史真实数据仍按供应商权限另行获取。
2. 抽出独立账户引擎、统一数据schema与策略接口，移除依赖恢复档案的默认运行路径；旧输入/结果继续冻结为回归基准。
3. 保留少量代表策略：量价树模型、趋势、条件切换、固定配置、风险预算；其他方法放扩展研究，不强迫用户安装Torch或拿到所有供应商数据。
4. 增加针对真实会计错误的测试和CI：股息/送转不重复计算，非负现金，费用最低收费和历史费率，T+1，信号先于成交，分红应收和税负，float32排序一致性，跨年持仓连续；测试不证明真实盘口成交。
5. 提供CSV/Parquet适配、来源说明、经过许可审查的数据获取流程、中文/英文快速开始、可视化教程、版本与贡献流程；许可证须核对本项目与引用代码来源后决定，不自动授予第三方权利。

优先把它做到一个外部研究者可安装、可演示、可接自己数据、可扩展的专门工具。GitHub推广、长期维护和外部反馈随后决定社区价值；无法保证Star数量。完整平台或实盘系统属于另外的长期工程，不应因本次讨论改动富国基金目录或原正式提交ZIP。
